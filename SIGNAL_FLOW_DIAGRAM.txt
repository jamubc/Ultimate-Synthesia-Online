═══════════════════════════════════════════════════════════════════════════════
                                 LATENCY ANALYSIS
═══════════════════════════════════════════════════════════════════════════════

Direct Path (Track → Master):
  Input → Gain → Pan → Analyser → Master
  Latency: ~0ms (direct connection, no processing)

Aux Send Path:
  Input → Gain → Pan → Send → Aux Effect → Return → Master
  Latency: ~0-10ms (depending on effect type)
  • Reverb: Convolution ~5-10ms
  • Delay: User-controlled
  • Chorus/Flanger: <1ms

Group Path:
  Input → Gain → Pan → Analyser → Group Comp → Group Gain → Pan → Master
  Latency: <1ms (compressor lookahead minimal)

Sidechain Path:
  Source → Analyser → Sidechain Gain → Compressor control
  Target → Gain → Compressor → Pan → Output
  Latency: ~1-3ms (compressor attack time)

Overall System Latency: <10ms for most paths (inaudible)
